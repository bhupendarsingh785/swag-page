# sounds/ folder — yahan apni sound files daalo

App pehle isi folder se sound uthata hai: `sounds/<scene>.mp3`

Naam yahi rakhna:
- `jungle.mp3` — jungle ambience (chidiyan, patte)
- `cave.mp3` — gufa (paani ki boond, goonj)
- `night.mp3` — raat (jhingur, hawa)
- `river.mp3` — nadi / paani

## Files kahan se (license dhyan rakho)
| Site | Kaise | Note |
|---|---|---|
| Freesound | API key se app khud laata hai (preview mp3, bina OAuth) | credit dena zaroori |

| Mixkit | manually download | free license |
